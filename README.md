# shadcn/ui

Beautifully designed components that you can copy and paste into your apps. Accessible. Customizable. Open Source.

## Documentation

Visit [ui.shadcn.com](https://ui.shadcn.com) to view the documentation.

## Features

- **Designed for React**: Works seamlessly with Next.js, Vite, Remix, and Gatsby.
- **Accessible**: Built on top of Radix Primitives for full WAI-ARIA compliance.
- **Customizable**: Complete control over styling with Tailwind CSS.
- **Copy and Paste**: Use the CLI or manually copy component code directly into your project.

## Quick Start

Run the `init` command to set up your project:

```bash
npx shadcn@latest init
```

Add components to your project:

```bash
npx shadcn@latest add button
```
